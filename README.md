# わくわく厳選メモ

モンストのわくわくの実を厳選するためのメモです。キャラの名前と、そのキャラで厳選したい実を書き留めるのが基本で、パーティでの相性判定はおまけです。HTML/CSS/JavaScript だけで動き、ビルドは要りません。

## できること

- 「キャラ」画面でキャラ名を入れるとき、ほしい実と目標の等級も一緒に選んで追加できる（4つまで。あとから追加・変更もできる）。種族などの入力は要らない
- 「まとめて選ぶ」から、ほしい実を一度に複数選べる。絆の実は「加撃系3つ」で加撃・加撃速・加命撃をまとめて選べる
- キャラ一覧の🗑から、その場でキャラを削除できる。削除などの確認はブラウザのポップアップを使わず、画面内のシートで出す（広告ブロックなどでポップアップが止められていても動く）
- 「データ → ほしい実の一覧に出す実」で、選択肢に出す実を自分で選べる。加速・加命・加速命はボタン1つでまとめて隠せる（すでにメモした実は消えない）
- 「キャラ」画面では、キャラごとに狙う実を「今の等級 → 目標・状態」の1行ずつで一覧し、その場で変更できる。「未完了」に切り替えると、まだ終わっていない実だけを見られる（英雄の神殿でリーダーにするキャラを選ぶときに使う）
- ☆を押したキャラは「優先」になり、キャラ一覧の上にまとまる
- 「バンク」画面にわくわくバンクへ入れている実（実・等級・個数）を登録すると、キャラやパーティの狙いと照らし合わせて「移せば厳選が終わるキャラ」を一覧にする。目標には届かないが今より等級が上がる候補も別枠で出す。「移した」を押すとそのキャラの実が完了になり、バンクの個数が1つ減る（直後なら元に戻せる）
- サブ垢などのアカウントを任意で登録し、キャラやバンクの実をアカウントごとに分けてメモできる。バンクはアカウントごとに別なので、同じアカウントのキャラだけを候補にする
- おまけとして、パーティ（4体）を組むと、絆系の実が何体に届くかや、同じ名前の実が重なって無駄になる組み合わせを表示する。種族・撃種・戦型はこのときだけ、キャラの画面で入れる
- メモは端末のブラウザに自動保存。JSON ファイルへの書き出し・読み込みで機種変更やバックアップに対応
- ホーム画面に追加すると、電波がなくても開ける（PWA）

## GitHub Pages で公開する手順

1. GitHub で新しいリポジトリを作る
2. この ZIP を展開し、中のファイル一式（`index.html` がリポジトリの直下に来るように）をアップロードする
3. リポジトリの **Settings → Pages** で、Source を「Deploy from a branch」、Branch を `main` / `(root)` にして保存する
4. 数分後に表示される URL（`https://ユーザー名.github.io/リポジトリ名/`）を開く

スマホで開いたら、ブラウザのメニューから「ホーム画面に追加」するとアプリのように使えます。

## ファイル構成

```
index.html              画面の骨組み
css/style.css           見た目（tai-hub と同じ配色・ダークモード対応）
js/data.js              種族・撃種・戦型・等級・実（ゲーム側のデータ）
js/app.js               画面の表示と保存の処理
sw.js                   オフライン対応（stale-while-revalidate）
manifest.webmanifest    ホーム画面に追加したときの設定
icons/                  アプリのアイコン
.nojekyll               GitHub Pages で Jekyll の処理を止めるための空ファイル
```

## 更新するとき

ファイルを書き換えてプッシュするだけで反映されます。Service Worker は stale-while-revalidate 方式なので、キャッシュのバージョン番号を上げる必要はありません。利用者側では、更新後に一度開くと裏で最新版が取り込まれ、次に開いたときから新しい内容になります。

新しい種族や実がゲームに追加されたら、`js/data.js` の `races` や `others` に追記してください。実の等級（`grades`）も同じファイルにあり、今は特級EL・特級L・特級Mの3つを高い順に並べています。目標の初期値は `defaultTarget`（特級L）です。

## 判定ルールの出典

実の重なり方は、次の攻略サイトの記載をもとにしています。ゲーム側の仕様変更があれば `js/app.js` の `analyze()` を直してください。

- 名前が違う加撃系（加撃・加撃速・加命撃）は重なり、同じ名前の絆の実は1つ分しか効かない：アルテマ「わくわくの実の重複」
- 一撃失心の力だけは同じキャラに複数つけても効果が出る：同上
- 超戦型は通常の戦型と同じ扱い：AppMedia「わくわくの実の効果一覧」
- 将命削りの力はパーティ内で重ならない：AppMedia「わくわくの実のおすすめ」

データの保存先はこの端末のブラウザ（localStorage）だけで、外部には送信しません。
